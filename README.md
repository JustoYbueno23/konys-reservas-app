# Konys Pizza - App Móvil de Reservas

Aplicación móvil para reservar mesas en Konys Pizza (Bucaramanga), construida con React Native y Expo para Android e iOS.

## Tecnologías

- React Native
- Expo (Expo Router)
- Supabase (base de datos)
- GitHub

## Cómo ejecutarlo

1. Clona el repositorio
2. Copia `.env.example` a `.env` y completa las credenciales de Supabase
3. Instala las dependencias: `npm install`
4. Inicia el proyecto: `npx expo start`
5. Escanea el código QR con la app Expo Go
